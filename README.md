# DaST: Data-free Substitute Training for Adversarial Attacks

The provided code is primarily the original code for the paper "DaST: Data-free Substitute Training for Adversarial Attacks" by M. Zhou et al. (paper here: https://arxiv.org/abs/2003.12703).

The source work is an implementation of an adversarial black-box attack method that trains a synthetic model for use in gradient based attacks without any of the target model's training data. All data is generated by a generator model that is trained in tandem with the synthetic model. Through training the generator model improves at generating examples that belong to each class and the synthetic model improves at imitating the behavior of the target model.

Once the synthetic model's behavior matches the target model's behavior, the synthetic model's classifier architecture, loss function, and trained parameters are used in gradient-based attacks (e.g., IFGSM) to generate adversarial examples intended to cause the target model to misclassify the input.

2. Replace `from torch.autograd.gradcheck import zero_gradients` in `/path/to/.conda/envs/<env>/lib/python3.9/site-packages/advertorch/attacks/fast_adaptive_boundary.py` with the following snippet of code: 
```python
def zero_gradients(x):
    if isinstance(x, torch.Tensor):
        if x.grad is not None:
            x.grad.detach_()
            x.grad.data.zero_()
    elif isinstance(x, container_abcs.Iterable):
        for elem in x:
            zero_gradients(elem)
```
# Usage
To train a synthetic model against Azure (the default):
```
python dast.py
```

To train a synthetic model against MNIST:
```
python dast.py --model=mnist
```

To generate adversarial attacks against and test them on the target model (NOTE: I did not test running this file):
```
python evaluation.py --mode=dast --adv=FGSM --cuda
```

# My Experimental Addition
I copied the `dast.py` file under the name `dast_unknown_class_number.py` and modified it.

The concept of my modification was to use DaST's method of exploring the input space of the target model without being trained on what the classes look like to learn the classes of a target model in a black box adversarial attack scenario where the number of classes in the target model is unknown.

The generator and synthetic model start with the architectures for two classes. The first class is identified when the first adversarial examples is generated and passed to the target. The second unknown class forces exploration. From this point on, after each new class is discovered a new deconvolution block is added to the the generator and a new output neuron is added to the synthetic model to get the model to keep exploring. The idea being that by the time the synthetic model is behaving like the target model, the input space has been explored enough that all of the classes will have been discovered.

The current implementation is experimental and incomplete. **It does not run.**

However, once completed it's usage for training a synthetic model is expected to be the same as the original `dast.py` file.
